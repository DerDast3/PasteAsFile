Paste As File
===========

### Desktop Application to Paste Clipboard Contents into Files

----------------

+ Supports any type of Text, Source Code, Markdown and Images.
+ Markdown content is detected automatically and offered as **`.md`**.
+ Change the current saving location or type it yourself.
+ Shortcut in Context Menu (Right Click)
+ Registering is done per user (no administrator rights needed)
+ to manually `Register` it run the application with this argument : **`/reg`**
+ to `Unregister` the application and remove the Context Menu Shortcut run it with this argument : **`/unreg`**
